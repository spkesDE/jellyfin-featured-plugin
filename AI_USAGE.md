# AI Assistance Disclosure

This project uses AI-assisted development tools as part of the development workflow.

AI assistance may be used for:

- analyzing Jellyfin Web HTML, CSS, DOM structure, and frontend behavior
- reviewing possible edge cases
- assisting with refactoring existing C# and TypeScript code
- suggesting TypeScript and Vue structure and module boundaries
- improving documentation and manual test checklists
- improving wording, spelling, grammar, and readability
- helping with issue responses, release notes, and project communication

All AI-assisted output is reviewed before it becomes part of the project.

The project remains maintainer-led. Architecture decisions, debugging, live testing, release decisions, and final code review are handled by the maintainer.

In particular:

- runtime behavior is tested and validated in a real Jellyfin environment
- carousel behavior, source rules, configuration structure, and project direction are maintainer-defined
- suggestions are reviewed, adapted, or rejected as appropriate
- the maintainer remains responsible for the final code and releases

AI assistance is also used for written communication, including documentation, release notes, issue responses, and other project text.

AI is used as a development aid and does not act as an autonomous maintainer of this project.
